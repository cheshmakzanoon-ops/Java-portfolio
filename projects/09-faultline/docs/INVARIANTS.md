# Invariants and failure boundaries

Faultline reasons about explicit local classfiles under its declared model. A complete scan establishes that modeled fixed points were reached within bounds; it does not establish program safety or exploitability.

| Invariant | Enforcement | Evidence |
| --- | --- | --- |
| Target code is never loaded or initialized. | The input layer reads owned bytes; ASM supplies structural facts only. The analyzer has no target classloader/reflection/execution path. | Packaged `CliProcessIT` and corpus sentinel test use a side-effecting initializer and assert that its marker remains absent. |
| Archive bytes, entries and paths stay bounded. | Bounded ZIP/ZIP64 central-directory preflight, indexed entry reads, checksum/size verification and actual expanded-byte accounting, including directory payloads; reject special files, traversal, duplicate names, symlinks and nesting. | `ArchiveIntegrityTest` and `EngineTest` archive bomb/corruption/duplicate/traversal tests, valid ZIP64 control and FIFO refusal. |
| Joins only grow information. | Source/context-bit union plus independent unknown; method/frame/heap joins are weak. Sanitization removes only the modeled context bit. | Fixed-seed `LatticePropertiesTest`, exact `EngineTest` semantic assertions and schedule-independent corpus comparison. |
| Stack/local categories agree at supported joins. | Computational kinds on operands, receivers and returns; strict stack joins, local TOP merges, category-two local widths, incoming/outgoing maxStack, handler/range validation and reachable terminators. | `OpcodeTest`, `VerifierFramesTest`, loop/wide/handler cases and every reachable corpus frame. |
| Unknown never becomes clean through an unsupported call. | Native alternatives remain in dispatch; opaque reference operands receive uncertain effects and mutable returns retain a stable identity plus possible operand aliases, including void effects. Unsupported bootstrap/lambda effects produce partial diagnostics. | `InvocationSemanticsTest` native dispatch, opaque fresh/alias returns, helper writes and allocation-length controls; `BoundaryTest` bootstrap/native cases. |
| Field and container mutations retain reference connections. | Weak field identities; bounded iterative allocation/formal/mutable-return alias closure; element and scalar-field write summaries. Method-qualified symbolic labels prevent foreign parameter rebinding. | R8/R9 positive and constant-only controls; direct controls and full current clean certification pass. |
| Provenance cannot delay fixed-point termination. | Call-path growth is limited separately from lattice state. Truncation affects explanation, not source taint. | Corpus provenance-zero comparison and recursion tests. |
| Resource exhaustion stays visible. | Shared work/deadline budget covers parsing, hierarchy/CFG/SCC setup and solving; explicit unfinished frontier and exit3. | Parser/frame/work/deadline/dispatch tests, `StructuralCoverageTest` completed-parser-prefix frontier, and packaged partial CLI case. |
| Baselines match exact identities. | Rule/source/sink tuple hashing; domain-separated lossless fallback for delimiter/unpaired UTF-16 names, ordinary hashes preserved. | `StableIdentityTest`, unrelated-method stability, actual two-surrogate-method finding/DOT control and exact baseline tests. |
| Every output preserves protected input bytes. | Destination guard resolves symlink parents before `..`; every report/DOT uses sibling temporary replacement and symbolic output refusal. | `ExplanationOwnershipTest` actual class symlink/hardlink preservation and CLI output-alias regressions. |
| Metadata target lookups stay bounded. | One reverse opcode-target index; branch/switch/range lookups do not rescan metadata. | `StructuralCoverageTest` instrumented repeated lookups require zero forward metadata traversals. |

Default input limits are25,000 entries,200MiB expanded,8MiB per entry/class, expansion ratio100, no nesting, and120s. ZIP central-directory metadata has an additional16MiB cap before index allocation. Analysis defaults are50million work operations,120s,32 dispatch targets and5 provenance steps. Additional bounds are2million retained visitor/alias facts,8million cumulative frame cells,4096 identities per taint/reference/alias value and10,000 diagnostics. These are conservative resource envelopes, not asymptotic guarantees. Exceeding a supported analysis bound produces partial coverage; invalid archive/configuration produces failure. Full benchmark completion remains an independent release gate.

One-callsite taint-summary contexts do not imply context-sensitive heap aliases. Reused mutable helpers can contaminate an independent clean call; the actual false-positive control is preserved in `../evidence/controls/`. See [threat model](THREAT-MODEL.md) and [review](REVIEW.md).
