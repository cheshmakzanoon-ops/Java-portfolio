# Review record

This record summarizes defects and their regression boundaries. Historical certification envelopes remain under `evidence/`; their source hashes and test totals do not certify later changes.

| Finding | Correction and regression |
| --- | --- |
| Concurrent permission updates could assign increasing versions before publication, letting a delayed older writer overwrite a newer scope. | Per-principal `ConcurrentHashMap.compute` now performs revision allocation and publication in one atomic operation; a new real-thread test verifies version monotonicity, revocation and isolation. Requires current Java 25 reactor/CI revalidation. |
| Payload-bearing ZIP directories bypassed expanded-byte accounting when the next entry implicitly drained them. | Bound every streamed member; reject directory payloads and mismatched local/central name, method, CRC and sizes. ArchiveDirectoryTest uses adversarial binary fixtures. |
| A failed first publication could leave an orphan committed directory that blocked all later startup. | Remove only the owned uninstalled destination; preserve uncertain outcomes. GenerationLifecycleTest checks restart and successful later publication. |
| A failed fallback-pointer repair could quarantine valid PREVIOUS and expose a reader without repaired CURRENT. | Separate validation from repair; operational repair failure closes readers, fails startup and preserves the fallback. |
| Multi-tenant close could close one reader before rejecting another tenant's live lease; lease admission could race a preflight check. | Freeze every publisher's admission first and roll back all freezes on rejection. EngineLifecycleTest and GenerationLifecycleTest cover lease rejection, reuse, writer wait and lock ownership. |
| Failed/cancelled/revoked builds accumulated owned staging directories. | The builder disposes failed staging; the coordinator disposes successfully built but unpublished staging and rechecks authorization immediately before publication. |
| An ordinal-loop increment mutation exhausted the heap while filling a growable scoring list. | Fixed-size ordinal storage makes the admitted candidate count an allocation boundary. The independent three-leaf/unordered-candidate regression preserves score ownership; strict mutation completion rejects runner failures. |
| Snippet offsets were taken from lowercased text and used against original source; Unicode case expansion could crash a valid search. | Literal case-insensitive matching now returns original-source offsets; snippet boundaries preserve surrogate pairs. SnippetBuilderTest covers expansion, both supplementary boundaries and literal metacharacters. |
| A frequently reused cached response retained its original five-minute cursor indefinitely. | Cache immutable content/next offset and sign on each response. CursorCacheLifetimeTest advances a virtual clock beyond expiry across cached first/middle pages and verifies valid continuation without accepting expired tokens. |
| Serving and source-audit usage reranking applied different ablation rules. | SearchRankingPipeline centralizes candidate/feature/usage policy. SourceServingTest compares exported and served ordering across the disabled feature modes. |
| Exact declaration fields bypassed the analyzer's maximum Lucene term size. | Apply the same normalized UTF-8 term bound to exact hints; preserve complete source and ordinary searchable text. IdentifierTermBoundaryTest builds real indexes with large ASCII, CJK and case-expanded declarations. |
| CAS could persist objects larger than its read quota; checkpoint identifiers were resolved without symmetric validation. | Enforce object bytes and checkpoint digest/position bounds before persistent writes. IngestionSafetyTest checks rejected paths and absence of oversized objects. |
| Offline phase identity depended on a handwritten class list and could omit extracted inference/evaluation helpers. | Bind complete inference origins plus the entire evaluation artifact/class tree for every caller, including constant-named wave2 phases. Frozen historical identities remain historical; new phases reject changed artifacts. |
| Legacy development evaluation interpreted held-out text and labels before claiming the final seal. | EvaluationJudgments filters split prefixes before payload parsing; run loads held-out records only after final selection/seal checks. Poison-heldout synthetic fixtures exercise the boundary. |
| Tenant administrators could observe process-global request/failure/queue activity. | Counters and pending-task ownership are tenant-scoped; TenantMetricsTest populates distinct tenants and a failed foreign job. |
| Failed development-token persistence leaked an already bound issuer; adapter shutdown left tasks running. | Failed bean startup closes its issuer. HTTP shutdown cancels and joins build tasks before engine destruction. IssuerLifecycleTest verifies immediate port reuse. |
| Invalid CLI commands could create/open data; study packet writers could emit data their readers reject. | Validate commands first; apply UTF-8 byte quotas and path representation checks before CREATE_NEW. Benchmark output requires a new directory. |
| An ambiguous publication could leave an old job retryable after a newer job completed. | Committed job identity and checksummed receipt reconciliation preserve the newer generation across live retry and restart. |
| Selecting a nested file changed its document key relative to a full-root snapshot. | All selected paths remain relative to the configured repository root. |
| Raw score explanations exposed statistics from denied repositories. | Public explanations contain authorized-document features rather than raw Lucene statistics. Residual score/order dependence is documented. |
| Filter-map display text allowed cache/cursor identity collisions. | Versioned binary encoding uses lengths and sorted tuples; warmed-cache, facet, crossed-cursor, reorder, restart, and revocation tests exercise the boundary. |
| Inference identity omitted transitive classes and numeric profile values. | Complete supported artifact origins and actual numeric profiles bind scoring, cache, and cursor identity. |
| Every enum was treated as final for virtual dispatch. | Constant-specific class bodies prevent exact instance binding; static bindings and ordinary final enums retain supported behavior. |
| Supplementary identifier admission disagreed with facts and wire limits. | Identifier scanning consumes code points and applies the same 256-unit UTF-16 quota before parsing; exact-boundary and mixed-script regressions cover it. |
| A regex admitted supplementary queries longer than the usage graph's UTF-16 bound. | The identifier lane applies the same 128-unit bound; real cold and warmed searches cover the boundary and safe fallback to ordinary search. |

The relevance review rejected the initial smoke corpus before measurement and removed unsupported secondary labels before freezing the measured corpus. Both later final studies failed the declared quality targets and retained baseline. Existing protocols and seals remain historical records; no new quality or performance result is implied by this maintenance review.
