# Case study: uncertainty, heap effects, and bounded explanations

An independent preliminary review found that a helper writing `out[0] = input` updated a callee parameter-reference heap key, but did not connect that effect to the caller's array. Treating a void-returning helper as having no useful summary would silently lose a real source-to-sink fact. The chosen fix adds symbolic argument-element writes to method summaries, substitutes their taints and actual reference identities at each call, and propagates effects transitively. `BoundaryTest.helperArrayAndCollectionWritesReachCaller` checks the externally observable two-sink result.

The same review found a void-returning unsupported bootstrap was handled as if it returned a stack value. The fix preserves the descriptor's void shape while adding uncertainty and partial coverage; its regression asserts partial, rather than an invalid frame or clean success. A separate reader review replaced eager directory materialization with bounded lazy traversal, and hierarchy/SCC construction now uses iterative budgeted traversal.

A deliberate precision/performance tradeoff is object-insensitive fields and conservative array/collection element summaries. This bounds state but may join unrelated values or lose array-index correlation. An exact method-signature sanitizer model preserves rule contexts but does not infer semantic equivalence between different whitelists. Unknown calls preserve taint and lower confidence, rather than promising an unsupported library's behavior.

A regression-confirmed false positive is `String[] args = {"/bin/sh", "-c", "echo fixed", userInput}; Runtime.exec(args)`: the user value is a shell positional parameter, not command text, while the conservative array summary joins all elements once the shell markers are present. This bounded model reports it. The example is outside the frozen confusion matrix and is disclosed, not suppressed or labeled as a real exploit.

Unsupported behavior includes a custom bootstrap that manufactures a tainted object independently of its arguments. The scanner cannot infer that implementation; it reports unknown and partial instead of a clean value. Detailed uncertainty is part of the product, not a claim of universal soundness.

Initial mutation testing killed111/164 mutants (68%, below the unchanged70% gate). Monotonicity properties alone did not assert that sanitization preserves unrelated context bits: an implementation that removed every label could remain monotone. Direct semantic assertions now check exact context masks, symbolic substitution intersections, incomparable lattice values, basic-block partitions, instance/wide locals, and empty methods. The original survivor inventory and raw report were preserved instead of excluding classes or lowering the gate.

The strengthened unchanged-target mutation suite now kills164/177 mutants (92.66%), leaving13 explicitly retained CFG boundary/worklist scheduling/reservation survivors. They are not asserted equivalent. Independent follow-up also found field/returned-reference loss and scalar field reads bypassing unknown-object mutations; bounded weak alias closure, method-scoped symbols and receiver-content joins now pass positive/unknown/matched-clean regressions. Lambda implementation handles now enter the call graph, with schedule-equality proof and unsupported native/virtual/mutable-return behavior explicitly partial. The actual reused-helper control exposes clean-call heap contamination rather than claiming callsite summary keys make the heap context-sensitive. Three full10,000-class scans and A08 source/evidence review now pass; repository-wide release verification remains separate.

A final resource review reproduced an OOM from a65,627-byte class with a JVM-invalid parameter descriptor: setup repeated a large method identity before charging work. Descriptor parsing now checks grammar, array dimensions and JVM slot limits linearly before argument allocation, and compact method scopes avoid retaining full identity strings in every label. SHA-256 uses the raw UTF-16 code units so legal lone-surrogate strings cannot collapse through replacement encoding. Five descriptor/budget methods plus real64MiB packaged-child regressions cover invalid and legal boundaries. The exact old input now fails safely with exit2; the valid long-name/255-slot input completes. This corrected input rejection is distinct from the10,000-class supported-workload performance claim.
