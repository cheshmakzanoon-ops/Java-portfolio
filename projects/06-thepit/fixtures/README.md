The canonical executable fixture is `Demo.fixture()` in simulator. It records all four initial account balances and all twelve commands.

Seeded generator version 2 (`SeededHistory`, `v2-live-identity-shuffled-block`) uses seed 42006006 and 64 accounts. Every independently shuffled 100-command block contains exactly sixty NEW, twenty-five CANCEL and fifteen REPLACE commands. NEW/REPLACE prices are uniform ticks 9900..10100 and quantities 1..10; NEW orders use GTC without post-only. Cancel/replace selects a live order with its actual account/side, or deliberately selects a unique missing identity if the book is empty. The driver records the complete outcome distribution, active/empty selections and observed peak/final book sizes; the configured 100,000-order cap is not an observed-depth claim. Duplicate injection is separately scheduled every 1000 commands, including command zero. See `docs/PERFORMANCE.md` for measurement boundaries and the reason version 1 was replaced before any accepted baseline.
