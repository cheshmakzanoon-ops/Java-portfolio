# RouteWeaver invariants

These are executable guarantees, not claims of global optimality. Domain and planning tests run without infrastructure; PostgreSQL tests use the real pinned server. Final acceptance evidence must name the exact tested source and root POM.

| Invariant | Enforcement | Adversarial evidence |
| --- | --- | --- |
| Immutable, bounded snapshots | Model records copy nested collections; jobs ≤ 500, vehicles ≤ 25, locations ≤ 501; complete square directed matrix, zero diagonal, integer seconds/meters/grams | ModelTest rejects malformed matrices, bounds and residual inconsistencies; canonical identity/deep-immutability assertions |
| Explicit units and safe arithmetic | Arc/Job/Vehicle bounds; checked long addition/multiplication for objective; strict Json mapping rejects fractional numbers, numeric strings and null primitives | ModelTest overflow/limits; SecurityTest typed-record negatives; HttpInputTest actual signed HTTP 400 before persistence |
| Input identity includes the entire workload | Model.Problem.canonicalHash includes matrix, objective, residual, completed/frozen state and versions | ModelTest canonical identity; PlanningTest cross-version incumbent rejection |
| Exact disjoint remaining-job partition | Validator reconstructs assigned IDs and independently checks duplicates, missing/unknown jobs and assigned/unassigned overlap | PlanningTest partitionDuplicateAndUnknown and structuralViolationsCannotMaskEachOtherAndReasonsDoNotOverclaim |
| Every vehicle has an explicit route, including empty routes | Validator checks missing, duplicate and unknown vehicle routes | PlanningTest structural violations; oracle enumerates empty routes |
| Cargo stays where it physically is | Validator rebuilds ownership from onboard sets; non-depot vehicles cannot acquire depot cargo; load starts with observed load plus newly loaded depot demand | PlanningTest residualCargoFreezeAndStranded; VerificationTest breakdown; nonzero shared-depot regression |
| Service-start windows and shifts have identical semantics | arrival = departure + directed travel; serviceStart = max(arrival, earliest); serviceStart ≤ latest; service and return finish within shift | PlanningTest skillsCapacityWindowsShiftAndReturn; exact return boundary and cross-midnight waiting cases |
| Return uses the declared depot and every directed arc | Validator computes the complete route including final return; common depot is Problem.depot, never implicitly location zero | Analytical reversal costs 330 versus 2310; nonzero depot test; original moves call the reference evaluator |
| Completed and frozen work is preserved | Replanner only advances an observed completed prefix; completed jobs leave remaining demand; frozen prefix survives unless failed commitments are explicitly released and audited | PlanningTest unsupported observations/freeze/cargo; VerificationTest breakdown; live Driver assertions |
| Broken cargo remains visible | Failed vehicles do not dispatch; undelivered onboard jobs receive STRANDED_CARGO; no transfer or remote reload | Residual validator tests and live breakdown assertions |
| Hard violations cannot trade against soft benefit | Score compares hard, weighted unassigned priorities, then operating cost + disruption lexicographically | ModelTest lexicographicScoreAndExplicitDispatchability; forged score rejection |
| Incumbents are independently validated and same-input only | Heuristics.retain reconstructs the challenger score and checks hash; Timefold mutable objects remain confined | PlanningTest objectiveAndIncumbentRetention, forgedSolverScoreCannotMakeInvalidCandidateReplaceIncumbent |
| A heuristic miss is not an impossibility proof | Validator explanations distinguish validated physical reasons from SEARCH_UNASSIGNED uncertainty | Exact-capacity/search-uncertainty assertions; complete oracle has OPTIMUM/INFEASIBLE/INCONCLUSIVE outcomes |
| Exact optimum requires exhausted enumeration | ExactOracle includes unassigned choices, all vehicle assignments and every permutation; bound seven jobs/two vehicles; interrupted optimum is null | Analytically solved fixtures and complete 95,901-leaf enumeration |
| Durable queue and CPU work are bounded | Admission advisory lock caps outstanding jobs at 17; one CPU worker/process, bounded executor queue; submit returns 429 at capacity | PostgresIT admissionBoundsAndQueuedCancellation; solve never runs on HTTP threads |
| Recovery never mislabels new computation with an old source | Dispatcher compares configured executing source with submitted job source before any planner; mismatches terminate through Store.finish, retaining historical incumbent and emitting no new candidate | PostgreSQL queued/expired-source/same-source regression; DECISIONS/003 describes conservative upgrade refusal |
| Only a live fenced generation writes authoritative progress | Candidate/terminal transaction locks job row and checks state, generation and database-clock lease; reads may be sampled, writes never are | PostgresIT leaseRecoveryFencesExpiredWorkerAndStoresHistory; cancelled lease recovery and stale completion cases |
| Cancellation has honest legal states | QUEUED → CANCELLED; RUNNING → CANCEL_REQUESTED → CANCELLED unless completion serialized first; terminal cancellation idempotent | Five concurrent cancel/finish schedules; Timefold startup barrier; CancellationPollTest latching/bounded reads |
| Publication is a separate compare-and-set | Current active problem/hash and plan revision are checked under locks; terminal retained valid incumbent required | Two publisher race has one winner; superseded input returns 409; cancellation never auto-publishes |
| Persistence snapshots are immutable | PostgreSQL update triggers reject changes to problem_snapshot and solution_candidate | PostgresIT databaseRefusesMutationOfImmutableInputAndCandidateSnapshots; restore test checks restored trigger |
| Tenant and authorization context never comes from a URL alone | Verified typed JWT tenant is included in every exposed lookup; GET/read and mutation/write scopes; static shell contains no tenant data | Real local RSA OIDC negatives, cross-tenant Store/HTTP tests, anonymous shell 200 and API 401 |
| Raw body is bounded before parsing | BodyBound reads at most 16 MiB + 1 including chunked requests | Real protected chunked HTTP 413 |
| Time zone ambiguity is explicit | UTC instants internally; service ZoneId for display; ambiguous local time requires offset; nonexistent time rejected | ModelTest timeZonesAmbiguousNonexistentAndCrossMidnight |

Cancellation polling can delay observation by up to 100 ms plus an in-flight bounded database operation. It cannot confer authority: every candidate, finish and publication repeats the database checks. Budget expiry is cooperative rather than a promise to interrupt an individual validation or JDBC operation instantly.
