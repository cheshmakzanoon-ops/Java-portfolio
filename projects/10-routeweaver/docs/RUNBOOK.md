# Operations

Start/build/demo/down commands are in README. Builds must pass before the launcher writes a source fingerprint stamp; startup and drivers reject changed handwritten source/POM/resource inputs. Generated binaries are never accepted just because a JAR happens to exist. Ports are19000HTTP/19001PostgreSQL, loopback by default and independently overridable. Compose volume survives `down`. Reset action deletes only the explicit `demo` tenant's seeded data and requires the trusted development profile.

Protected mode discovers the configured local OIDC issuer/JWKS and verifies RSA/JWS signatures, issuer, expiry, subject, audience, tenant shape and endpoint scopes. API GET requires routeweaver.read; mutations require routeweaver.write. Only health and the static shell at / and /index.html are public so users can enter a Bearer token before requesting protected data. Integer-unit JSON fields require integer tokens; fractional numbers, numeric strings and null primitives return400 before persistence. Text fields reject numeric and boolean scalar coercion. A token has one tenant; all exposed identifiers are resolved together with that tenant. No token or real credential belongs in source/evidence. Set ROUTEWEAVER_DB_URL/USER/PASSWORD, ROUTEWEAVER_ISSUER, ROUTEWEAVER_AUDIENCE as environment bindings.

A solve budget is1–30,000 milliseconds, with1–100,000 Timefold steps, explicit seed and idempotency requestId.17 outstanding jobs are admitted globally; further requests return429. CPU pool is one per process; deployment capacity is bounded by service replica count. Read jobs until terminal; cancellation returns actual QUEUED/RUNNING/CANCEL_REQUESTED/CANCELLED/COMPLETED state and never claims a hard immediate stop. Compare same-version baseline/candidate endpoints only.

After worker loss, a15-second lease expires. Polling/startup requeues RUNNING with a newer fence, preserving its last validated incumbent; expired CANCEL_REQUESTED becomes CANCELLED. A different live service never steals an unexpired lease. A previous worker's candidate remains historical/diagnostic. Do not edit generation/state columns to bypass fencing. Database clocks, not host clocks, determine expiry. PostgreSQL transaction statement/lock timeouts bound blocked operations. All terminal/candidate authority checks lock the row and check legal state/fence/lease together.

Publishing requires solveJobId, expectedVersion and expectedRevision.409 means refresh active input and plan revision, then solve/validate the current snapshot; repeatedly resending an obsolete candidate cannot succeed. CANCELLED jobs with retained valid incumbents can be manually published through those same checks and never auto-publish. New urgent/breakdown revisions intentionally change the workload; do not report a cross-version score change as optimization improvement.

Replan at observed stop boundaries only. Frozen commitments on failed vehicles require explicit audited release; cargo remains on the failed vehicle and becomes STRANDED_CARGO. Remaining jobs and completed history are disjoint. Before deleting or resetting demo data, stop all its solves and use the named reset action; no global Docker pruning is supported.

The benchmark script executes ten preregistered inputs and three independent runs per input with raw score traces and GC logs. Instance9 is a directed operating-cost trap: all off-diagonal travel seconds equal1 while preferred ascending arcs cost1meter and all other arcs1000meters; nearest-time insertion deterministically generates an improvable baseline. Its10% cost reduction within30 seconds is a proposed tuning goal only until measured. Record quiet-host scheduling, CPU quota, JDK/JVM flags, warmup, complete input hash, source fingerprint, timestamps and containers. Heap snapshots are used-heap observations, not peak-memory proofs. In-memory validation throughput is separate from end-to-end HTTP/queue latency.
