# Durable format v1

All integers are signed big-endian Java DataOutput values. Startup refuses unknown versions.

A WAL record contains magic `0x514b5631` (4), version (4), total length (4), type (1), resulting last index (8), resulting term (8), payload length (4), payload, CRC32C (4) over all prior record bytes. Length is bounded to 64 MiB. Type 1 is the first complete full-state record of a generation: term, vote, safely established commit, snapshot and contiguous retained suffix. Type 2 is an atomic state transaction: term, vote, commit, common retained prefix length, added-entry count and entries. The common prefix compares the complete semantic entry, including command payload bytes; equal index/term alone cannot hide a changed payload. A suffix repair is encoded by shortening the common prefix and adding its replacement in the same record. A complete CRC failure anywhere aborts startup; a final incomplete header/body may be truncated to the previous complete record. Only a successfully forced record can release a dependent acknowledgment.

`MANIFEST` is `QKV1 <generation> <snapshotIndex>`. It selects `wal-<generation>` and `snapshot-<index>`. Snapshot serialization includes version, included coordinates, exact cluster ID, fixed member IDs0/1/2, sorted key/value contents and sorted session state. Its internal CRC32C protects chunk assembly; the stored snapshot file also has an outer CRC32C. Recovery validates snapshot checksums and exact equality with the snapshot referenced by the selected full WAL record, retained index continuity, entry terms and commit bounds. No fallback to an older generation silently discards acknowledged history.

Snapshot publication crash points are named SNAPSHOT_FLUSH, SNAPSHOT_RENAME, GENERATION_FLUSH, MANIFEST_FLUSH, MANIFEST_RENAME, DIRECTORY_FLUSH. Ordinary write boundaries are WAL_WRITE and WAL_FLUSH. Tests reopen the real filesystem at each publication point and assert acknowledged state survives. Virtual disks separately model loss before durable completion. Actual-process tests use forced JVM termination, not a claim of cutting power to physical storage.

Ordinary WALs rotate after 8 MiB into a full-state generation selected by the same publication protocol. Current and preceding generations/snapshots remain; older covered artifacts retire only after directory durability. A full record above 64 MiB fails explicitly before allocation/publication.

A failed write/publication poisons that journal instance. Further persistence is refused until close and validated recovery; the implementation never appends behind an uncertain tail. A granted vote cannot change within a term, and retained committed entries cannot be rewritten. These checks strengthen state-transition validation without changing version-1 bytes.
