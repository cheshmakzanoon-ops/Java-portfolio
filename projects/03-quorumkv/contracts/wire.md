# Wire protocol v1

TLS 1.3 wraps a 4-byte big-endian length prefix (maximum body 512 KiB). Body: magic QKV1, version 1, modified-UTF cluster ID, source ID, destination ID, modified-UTF role token, 64-bit correlation, one-byte body tag, typed fields. IDs 0–2 are authenticated peers; 3 is client; 4 is local administration. Frames authenticate before owner dispatch.

Body tags: 1 peer RPC, 2 mutation, 3 GET, 4 administration, 5 response. RPC tags: 1 RequestVote, 2 vote response, 3 AppendEntries, 4 append response, 5 InstallSnapshot chunk, 6 snapshot response. All RPCs include term and request identity; append includes log coordinates, at most 32 entries, commit and read correlation. InstallSnapshot includes leader, included index/term, offset, bounded total, chunk length and at most 16 KiB of bytes. Chunks activate only when the assembled, checksummed snapshot's cluster and coordinates agree. Interrupted transfers restart at offset zero.

Mutation: client ID (max 128 chars), positive contiguous sequence, kind PUT/DELETE/CAS, key <=256 bytes, value/expected <=4 KiB each. The digest is SHA-256 of the canonical typed payload, recomputed from validated fields. Results: OK, CAS_MISMATCH with observed value, NOT_LEADER with hint, UNAVAILABLE, UNKNOWN_OUTCOME, RESOURCE_EXHAUSTED, SEQUENCE_GAP, STALE_SEQUENCE, IDENTITY_CONFLICT. Null and empty byte values differ. There is no JSON or Java serialization fallback.
