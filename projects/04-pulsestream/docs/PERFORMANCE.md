# Performance methodology and observed evidence

`fixtures/workload-v1.json` specifies the required seed 4404, eight partitions, 10,000 keys and one million measurements. Every thousandth index is duplicated; every tenth index is reordered by fifteen seconds. `scripts/benchmark.sh full` prepares the real Kafka input then measures bounded poll/engine/SQL drain, with snapshot, results, checkpoint and outbox insertion in the durable boundary. Kafka preparation is reported separately. Outbox publication is excluded and labeled. `smoke` explicitly uses 10,000 measurements/100 keys and cannot substitute for the full workload.

This is a closed-loop drain of preloaded durable input. Checkpoint p50/p95/p99 includes engine transition and SQL transaction, excludes queue waiting, and therefore has coordinated-omission limits. Reported accepted throughput covers the whole drain/start/close interval. The driver reports actual sample count, maximum queued batches, peak observed (sampled, not absolute) heap, PostgreSQL database size/growth, and SQL restore/source-seek recovery time.

`EngineBenchmark` uses JMH with two one-second warmups and three one-second measurements, three independent forks in `scripts/benchmark-engine.sh`. Each invocation computes a fresh 500-record transition with eight partitions. The `@OperationsPerInvocation(500)` result is engine measurements/second, not durable service throughput. The benchmark consumes its returned state. It measures fresh-state ingestion rather than a million-ID dedup table and must not be used to infer long-run performance.

Expected bottlenecks to investigate: copying the finite dedup map, compression of full open-state snapshots, and deletion/reinsertion of current pane rows. These have not been hidden behind a fake throughput target. Three independent isolated runs are required before publishing a stable baseline. Shared-host contention must be recorded. Current observed run evidence and unresolved measurement gates are in STATUS; raw runtime artifacts belong in `.work/A04/runtime`, not Git.
