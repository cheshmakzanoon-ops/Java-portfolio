# ADR 002: typed dataflow is engine semantics 2

Accepted for the next executable version; verification remains recorded in STATUS.

The earlier engine compared declared edge types but carried strings and sent the original execution input to every activity. That did not implement typed dataflow. Adding type tags to the same ignored strings would leave the defect in place.

Semantics 2 has a restricted scalar algebra: TEXT holds only a bounded Java/JSON string, INTEGER holds only an integral 64-bit JSON number, and BOOLEAN holds only a Java/JSON boolean. No string, floating-point, boolean, collection or numeric coercion is allowed. An execution records a typed root payload and typed context whose names and types must exactly match definition variables. The root's declared input type must match the payload.

Every successful node produces a homogeneous vector of typed values. Its outgoing declared type is the element type. Activity task parameters contain immutable execution context, actual predecessor outcomes, and flattened predecessor values. Compiled pure echo, checked integer sum and boolean not activities consume those values; provider activities receive the full canonical typed parameter document. A changed parameter document conflicts at the provider. Results and signals are validated against the active task/node's declared type before any state/history transaction commits. Compiled provider activities, sum and not produce one scalar; pure echo preserves the actual argument-vector length. The same cardinality invariant applies to recorded completion, APPLIED reconciliation and authorized worker completion, so malformed results cannot defeat activation's vector-size bound.

A durable timer passes its arguments through after the recorded firing event; it never synthesizes the business string "timeout". A signal timeout records TIMED_OUT with no scalar value. SKIPPED likewise has no scalar value. Normal downstream activities are skipped when a prerequisite has no value. A pure status predicate may explicitly branch on VALUE, SKIPPED or TIMED_OUT. Pure value predicates require one scalar predecessor result and compare a literal parsed according to its declared type. Context predicates use declared context types.

A PARALLEL_ALL join flattens successful predecessor vectors in definition dependency order, excludes deliberately skipped branches, propagates a timed-out prerequisite, and becomes skipped when no branch produced a value. Graph COMPLETED means all finite nodes are settled; returned outcomes expose skipped/timed-out business paths. It does not imply every possible branch or external effect occurred. Compensation consumes the completed forward step's actual typed result, with its own stable logical identity.

The engine-semantic pin changes to 2. An additive migration labels existing definitions as semantics 1 and preserves their original JSON/history. Frozen LegacyDefinitionV1 and LegacyInterpreterV1 adapters keep the original string interpretation, while existing instances retain their original hashes, parameters and worker behavior. New definitions are deployed as semantics 2; an incompatible definition change requires a new immutable version. No running history is silently reinterpreted or rewritten.
