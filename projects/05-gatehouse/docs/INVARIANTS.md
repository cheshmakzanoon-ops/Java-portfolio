# Invariants and verification

The implementation links locate the contract; test names locate executable counterexamples. Passing results and scope limits are recorded separately in [status](STATUS.md).

| Invariant | Implementation | Verification |
| --- | --- | --- |
| An allow needs a scope-matching grant and true ABAC allow; explicit deny and unknown are conservative | [PolicyEngine.decide](../policy-core/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/PolicyEngine.java) | `inheritedGrantAndAbacBothRequired`, `grantScopesCannotCrossActionsResourceTypesOrAssignedRoles`, 2,500 independent interpreter comparisons |
| Parser types and finite work budgets are enforced at inclusive boundaries; malformed Unicode cannot collapse digests | [PolicyLanguage](../policy-core/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/PolicyLanguage.java) | `languageBudgetsAcceptTheirBoundaryAndRejectTheNextValue`, `everyLogicalOperandMustBeBoolean`, `directExpressionEvaluationCannotExceedItsIndependentWorkBudget`, `malformedUnicodeCannotCollapseDistinctPolicyDigests` |
| Role closure and derived indexes are immutable and belong to the compiler | [PolicyEngine.Compiled](../policy-core/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/PolicyEngine.java) | `compiledPlansOwnDerivedStateAndRejectForgedIndexes`, cycle/unknown-role tests |
| Cache identity includes tenant, immutable revision and digest; one concurrent load produces one plan | [CompiledPolicies](../decision-service/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/CompiledPolicies.java) | `CompiledPoliciesTest`: latched concurrent load, key separation, invalidation and failed-load retry |
| The verified original string subject is the only request identity; JWT role and tenant claims grant nothing | [DecisionApplication.trustedDecoder](../decision-service/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/DecisionApplication.java), [ProtectedDocuments.decoder](../demo-resource-server/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/ProtectedDocuments.java) | `JwtSecurityTest`, `ProtectedClaimsTest`, real OIDC adversarial integration |
| Context cannot overwrite subject/resource fields; invalid persisted state is unavailable, not bad caller input | [SnapshotAuthorization](../decision-service/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/SnapshotAuthorization.java) | `SnapshotAuthorizationTest`, stored-policy/attribute corruption integration |
| All nine protected tables retain RLS and FORCE RLS; runtime cannot own them or assume an RLS-bypassing role | [RuntimeDatabase.verify](../policy-store/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/RuntimeDatabase.java), [migration](../policy-store/src/main/resources/db/migration/V1__tenant_authorization.sql) | Integration disables each table boundary, removes a table, changes ownership and grants an adversarial role, restoring each afterward |
| No session tenant leaks across pool reuse; nested transactions cannot replace context | [PolicyStore.transaction](../policy-store/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/PolicyStore.java) | Pooled tenant isolation; real-connection context/setup, callback-Error and nested-call fault tests |
| Missing/inactive membership cannot invoke even a faulty allowing evaluator or resolve private metadata | [PolicyStore.decide](../policy-store/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/PolicyStore.java) | Independent store-callback integration counterexample and redacted mandatory denial audit |
| Every allow requires committed audit; failed mutations leave epoch, membership and audit unchanged | [PolicyStore.transaction / audit](../policy-store/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/PolicyStore.java) | Mandatory audit outage; injected commit failure with real rollback and suppressed rollback failure |
| Revocation before a new snapshot denies even with warm compiled plans; an old snapshot may complete | [PolicyStore.decide](../policy-store/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/PolicyStore.java), epoch triggers | Latched before/after snapshot integration, protected demo |
| Publication requires one canonical int64 precondition; rollback publishes a new immutable higher revision | [DecisionController.expectedVersion](../decision-service/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/DecisionController.java), store publication methods | `PublicationPreconditionsTest`, authenticated malformed HTTP cases, concurrent publication/rollback integration |
| Current-window quota counters cannot be evicted and each request releases its permit once | [TenantAdmission](../decision-service/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/TenantAdmission.java), [RequestBounds](../decision-service/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/RequestBounds.java) | Fixed-clock churn/overflow tests, 100 simultaneous contenders, duplicate-close and exception/body-bound tests |
| A protected read needs a fresh complete typed ALLOW; malformed or unavailable dependency responses refuse access | [DocumentAuthorization](../demo-resource-server/src/main/java/io/github/cheshmakzanoon/portfolio/gatehouse/DocumentAuthorization.java) | Local HTTP stub covers fresh allow/deny/allow, incomplete/ambiguous/oversized responses and transport faults; real protected demo |
| Finite helpers leave no owned descendants; failed startup removes only newly acquired resources | [run-bounded.py](../scripts/run-bounded.py), [up.sh](../scripts/up.sh) | [Process tests](../scripts/test_process_lifecycle.py): normal exit, deadline, terminal signal, migration and readiness failures |

Unit and oracle tests live in [policy-core](../policy-core/src/test/java/io/github/cheshmakzanoon/portfolio/gatehouse/PolicyEngineTest.java), [decision-service](../decision-service/src/test/java/io/github/cheshmakzanoon/portfolio/gatehouse/CompiledPoliciesTest.java) and [protected-service](../demo-resource-server/src/test/java/io/github/cheshmakzanoon/portfolio/gatehouse/DocumentAuthorizationTest.java). Database/OIDC counterexamples live in [AuthorizationIT](../verification/src/test/java/io/github/cheshmakzanoon/portfolio/gatehouse/AuthorizationIT.java). The process adapter tests verify shell control and resource ownership; they do not claim a real Docker outage drill.
