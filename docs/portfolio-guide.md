# Portfolio review guide

Start with the acceptance matrix. PASS requires executed evidence; an implemented algorithm or passing unit suite does not establish complete service, recovery, security or benchmark acceptance.

Review ClearLedger for SQL transaction boundaries, DurableFlow for external-effect uncertainty, and ThreadLens for observational overhead. The remaining projects cover consensus, streaming, authorization, matching, search, static analysis and optimization. Follow each project README into source, invariant tests and its case study.
