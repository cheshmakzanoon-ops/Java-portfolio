# Portfolio review guide

Start with the acceptance matrix. PASS requires executed evidence; an implemented algorithm or passing unit suite does not establish complete service, recovery, security or benchmark acceptance.

Review Daybook for SQL transaction boundaries, Handoff for external-effect uncertainty, and Backtrace for observational overhead. The remaining projects cover consensus, streaming, authorization, matching, search, static analysis and optimization. Follow each project README into source, invariant tests and its case study.
